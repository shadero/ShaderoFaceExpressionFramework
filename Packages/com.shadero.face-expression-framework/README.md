# Shadero Face Expression Framework

VRCFT の入力を加工し、表情 Clip と Gesture に結び付ける VRChat アバター向け Unity Editor ライブラリです。アバターごとの入力名・Clip・表情ルールは利用側で指定します。

- [API と使用例](Documentation~/FaceExpressionFrameworkApi.md)
- [設計](Documentation~/FaceExpressionFrameworkDesign.md)
- [要求](Documentation~/FaceExpressionFrameworkRequirements.md)

生成した Animator Controller のアバターへの組み込みは、利用側のプロジェクトで行います。
